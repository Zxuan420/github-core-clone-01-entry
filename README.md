A standalone, GitHub-compatible git forge in one Node process: git smart HTTP (upload-pack v2, receive-pack v0), REST v3, GraphQL v4 and MCP, over its own in-memory store. No UI, no outside service, no git binary.

## Run it

```sh
node main.ts
```

The forge binds an ephemeral port, registers it with `$MAKEFUN_ENV_URL/register`, serves the suite, then exits 0 when the env reports done.
